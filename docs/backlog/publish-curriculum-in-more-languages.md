# Publish the curriculum in more languages

- **Opened:** 2026-11-02, by the user, from the card
  [choose the licence of the articles](../done/2026-11-02_choose-articles-licence.md).
- **Status:** noticed, not started. In Later.

## Why

The curriculum is under CC BY-ND 4.0: anyone may copy it and pass it
on, but not share a changed version, translations included. A recruiter
working for a client abroad could not pass on a translation. The user
chose to translate the curriculum themselves and publish it in more
languages, so the versions in other languages are the author's own.

## Questions
