# Launch the site on LinkedIn

- **Created:** 2026-11-18
- **Status:** Open

## Why

The user told it on 2026-11-18, while deciding to publish the style
guide with the pages still to come declared (card
[show the breakpoints in the style guide](../wip/show-the-breakpoints-in-the-style-guide.md)).
Today the site is not promoted: readers reach it only through search
engines, and through a link on the user's Medium profile. The real
launch will be a post on LinkedIn, once the site has a few more
articles and the user can see who reads it. Until then a version
published with gaps reaches few readers, which is why publishing
early costs little.

Without this card the launch, and what it waits for, would live only
in a session's chat: the plan says that further articles are "not
planned yet, on purpose".

## What is known

- **What the launch waits for**, as the user put it on 2026-11-18:
  - observing the visitors, with Google Analytics or a tool like it
    (card
    [observe the visitors in production](observe-visitors-in-production.md));
  - a few more articles. The ones the user named:
    - one the user is writing now;
    - one on the work done on the rules for the agents, and on how
      the user sees the software development life cycle with these
      tools;
    - one from a talk the user gave years ago, whose slides first have
      to be cleaned of the employer's data;
    - one on a proof of concept that implements, in part, Data Context
      Interaction in Rust.
- **The search engine check is already in the build** (Lighthouse,
  card [check SEO with Lighthouse](../done/2026-11-07_check-seo-with-lighthouse.md)):
  the user first named SEO among the things to do before the launch,
  then said Google Analytics was meant.
- **Marketing campaigns may come with it** (card
  [plan marketing campaigns](plan-marketing-campaigns.md)).
