# Choose the licence of the articles

- **Opened:** 2026-10-28, from the light pass of `residuality`
  ([card](../done/2026-10-28_challenge-skeleton-with-residuality.md)).
- **Status:** noticed, not started. To decide before the first article.

## Why

The whole repository is under the MIT licence (`LICENSE`, `Cargo.toml`).
MIT fits the code, but articles kept in the same repository would be
under MIT too, so anyone could reuse them, even commercially, with only
the copyright notice.

On 2026-10-28 the user chose to keep MIT for now, and to consider a
Creative Commons licence for the articles later. The footer's copyright
line does not conflict with MIT, which carries the same notice.

## Questions

- Which Creative Commons licence, if any, for the articles.
- How code and articles are told apart in the repository, so each has
  its own licence.
