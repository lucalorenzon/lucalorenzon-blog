These are the fonts this site uses, each in every style it serves. Every sample shows the same text, so that only the font changes from one to the next.

## Literata

I chose Literata, the font of the text and of the page titles, for its readability.

## Hack

For the code I chose Hack, the lightest font I found to show code in the style of Meslo LG, its close relative. Meslo LG itself, the font of my first trials, was left out because of its licence.

## IBM VGA 8x16

IBM VGA 8x16 was my first choice, to give the site the look of the old BBS. It was a wrong choice, and I left it for readability. Today only the logo uses it, and it will go when the logo becomes an image.
