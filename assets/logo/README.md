# The logo

- Images: the round icons in this folder, and the site's favicon
  (`assets/favicon.ico`), cut from a photo by Gioia Greifenberg.

not be copied, changed or reused. The same notice is written inside
each of the icon's WebP files.

How the icons are made, from the original photo (842 by 1122 pixels,
never committed): the square of 760 pixels at 0 from the left and 110
from the top, cut to a circle with a transparent outside; reduced to
each size with Lanczos; sharpened (unsharp mask, radius 1.2, 80 per
cent, threshold 2); colour raised by 15 per cent and contrast by 8;
saved as lossy WebP, quality 90, with the notice above as XMP metadata
(`dc:rights`).

The favicon is made the same way, at 16 and at 32 pixels, each reduced
from the circle at its own size, and saved together in one icon file,
each image as a PNG with its transparency. The icon format has no place
for the notice, so it stays here and on the site's licence page.
